# Contribution Guide

**1. Reporting issues**

- If you find any issues, first check the [issues list](https://gitcode.com/Ascend/MindSpeed-LLM/issues) of the repository and look for similar issues or existing solutions.

- If the existing [issues list](https://gitcode.com/Ascend/MindSpeed-LLM/issues) does not contain the issue you encountered, [submit a new issue](https://gitcode.com/Ascend/MindSpeed-LLM/issues/create/choose) and provide a clear problem description, reproduction steps, and environment information.

**2. Performance optimization and new features**

- For performance optimization proposals, use the `Performance` label when submitting the issue and describe the optimization features and their usage scenarios.

- For suggestions or discussions about new features, use the `Feature` label when submitting the issue and describe the background, expected outcomes, and proposed solutions.

**3. Code contribution process**

If you would like to submit code changes, follow these brief steps:

- Develop and commit your changes on your personal branch, then submit a Pull Request (PR) to this repository. Common PR types include `feat` (features or scripts), `fix` (bug fixes), and `docs` (documentation changes).

- After submitting the PR, create an issue and associate it with the PR. Use the issue label that corresponds to the PR type: `Feature` (feature discussion), `Bug` (bug feedback), or `Doc` (documentation issues). We will discuss with you in the issue whether to adopt the proposal and provide comments or revision requirements. You can also follow up on subsequent progress through the issue.

- Revise the code based on the discussion and update the PR.

- Enter `compile` in the comment section to trigger the gate pipeline (CI).

- After the CI of the PR passes and the PR receives sufficient labels, the repository committer performs the final review and merges the changes into the in-development branch.

Thank you for your participation and contributions! We look forward to working with you to drive the project forward.
